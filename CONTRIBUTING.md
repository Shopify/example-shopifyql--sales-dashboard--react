# Contributing

This repository is a documentation sample. It's the companion code for the [Run your first ShopifyQL query](https://shopify.dev/docs/apps/build/shopifyql/graphql-admin-api) tutorial on shopify.dev, and the tutorial renders these files directly.

Because the content is tied to the tutorial, this repository **doesn't accept issues or external contributions**. To report a problem or suggest a change, use the feedback control on the [tutorial page](https://shopify.dev/docs/apps/build/shopifyql/graphql-admin-api).
